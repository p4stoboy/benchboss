# Protocol v2 Implementation Plan

> Execute with subagent-driven development where file ownership is independent; coordinate shared interfaces before implementation.

**Goal:** Ship the approved timing, lifecycle, replay, capability and named-resource update.
**Architecture:** Shared protocol definitions; pure referee execution; host-owned elapsed time.
**Tech stack:** Existing Bun/TypeScript workspace, Zod, Ajv, Biome. No new dependencies.
**Spec:** `docs/design-notes/2026-09-11-protocol-v2.md`.

## Constraints

Work on codex/chess in the primary checkout. Preserve existing chess changes. Keep protocol v1
runtime and frozen game revisions executable. Current authoring exposes named resources and
explicit timing. No commits/pushes by workers; parent integrates one coherent change-set.

## Task 1: Contracts and resource accounting

- [x] Own `packages/protocol/src/index.ts`, new protocol v2 modules, `packages/core/src/types.ts`,
  `packages/core/src/budget.ts`, `packages/schemas/src/` and their mirror tests.
- [x] Define exact types/validators from the spec, legacy aliases/unions and v2 capabilities.
- [x] Add tests rejecting malformed/negative/unknown resource definitions and costs, independent
  match/phase/decision resets, private/public projections, and incompatible envelopes.
- [x] Run failing focused tests, implement, rerun; publish exact exports to dependent workers.

## Task 2: Referee runtime and replay

- [x] Own `packages/referee/src/` and `packages/referee/tests/`.

- [x] Add phase/participation/timing readers, atomic expiry hooks, generic metering and exact replay.
- [x] Test cumulative conservation, waiting pauses, shared phase cutoffs, zero-actor expiry,
  exhaustion handler progress, finished permanence, generic sensing and tampered replay rejection.

## Task 3: Host and adapters

- [x] Verify admission failures, equality expiry, duplicate receipts, simultaneous seats, lifecycle

## Task 4: Catalog migration, documentation and integration (parent)

- [x] Update game tests, conformance, examples, guides, README and ARCHITECTURE with actual semantics.
- [x] Run focused regressions then `bun run check` and `bun test`; exercise real local HTTP match
